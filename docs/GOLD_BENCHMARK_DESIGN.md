# Gold 预印本评测方案

当前状态为准备阶段。公开设计见 [Gold Skill evaluation for the preprint](GOLD_PREPRINT_EVALUATION.md)，研究主张见 [Gold 研究主张与贡献验证指南](GOLD_RESEARCH_DIRECTION.md)。

首版采用单细胞构成和 bulk RNA-seq 两条真实数据案例链，比较完整 Gold、原始专家纠错检索和一个外部 Agent。外部对照的准备以 PantheonOS 为候选。三种配置合计计划 36 次分析任务，另有 4 次独立的准入短复盘。题目、专家预写纠错、评分材料和执行日志分别管理，以维持跨轮次评估的隔离。

每条链分别检查研究对象或重复单位、主结论是否由交付数据支持、正式交付是否完整，以及新场景中是否正确沿用或限制旧原则。评测前后的回答由独立会话产生，答案与评分不会进入学习会话。正式评测尚未开始。
